## Overview

TaskFlow merupakan aplikasi manajemen tugas modern yang dirancang untuk membantu pengguna mengatur aktivitas sehari-hari secara lebih terstruktur, efisien, dan produktif. Aplikasi ini dikembangkan menggunakan React.js dengan Vite sebagai build tool serta Tailwind CSS untuk menciptakan antarmuka yang bersih, responsif, dan nyaman digunakan di berbagai ukuran perangkat.

Project ini berfokus pada penerapan praktik terbaik dalam pengembangan frontend modern melalui pendekatan component-based architecture, reusable components, clean code, dan responsive design. Selain berfungsi sebagai aplikasi pencatat tugas, TaskFlow juga menjadi media pembelajaran untuk mengimplementasikan pengalaman pengguna (User Experience) yang lebih baik dengan tampilan yang sederhana namun profesional.

## Main Features

### Dashboard

Dashboard memberikan ringkasan aktivitas pengguna melalui tampilan statistik yang informatif. Pengguna dapat melihat jumlah keseluruhan tugas, tugas yang telah selesai, tugas yang masih berlangsung, hingga progres penyelesaian dalam satu tampilan yang sederhana.

---

### Task Management

TaskFlow memungkinkan pengguna untuk mengelola seluruh aktivitas harian dengan mudah. Setiap tugas dapat ditambahkan, diperbarui, ditandai selesai, maupun dihapus. Seluruh perubahan akan langsung diperbarui pada tampilan sehingga memberikan pengalaman yang responsif.

---

### Search & Filter

Untuk mempermudah pencarian data, aplikasi menyediakan fitur pencarian berdasarkan kata kunci serta filter berdasarkan kategori maupun status tugas sehingga pengguna dapat menemukan tugas tertentu dengan lebih cepat.

---

### Responsive Design

Seluruh halaman telah dirancang menggunakan pendekatan Mobile First sehingga dapat berjalan dengan baik pada Desktop, Tablet, maupun Smartphone tanpa mengurangi kenyamanan pengguna.

---

### Modern User Interface

Antarmuka dibangun dengan prinsip minimalis dan modern menggunakan Tailwind CSS. Tata letak yang bersih, pemilihan warna yang nyaman, serta penggunaan komponen yang konsisten memberikan pengalaman penggunaan yang lebih profesional.

---

### Dark Mode

TaskFlow mendukung mode terang dan gelap untuk meningkatkan kenyamanan pengguna ketika menggunakan aplikasi pada kondisi pencahayaan yang berbeda.
